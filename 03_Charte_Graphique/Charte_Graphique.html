15 — Accessibilité WCAG 2.1

Règles non négociables

CritèreRègleImplémentation Nuxt/Vue
Contraste Ratio ≥ 4.5:1 pour texte normal, ≥ 3:1 pour texte large N'utilisez jamais Neutral 400 pour du texte
Focus Outline visible sur tous les éléments interactifs au focus clavier :focus-visible avec outline 3px brand-400 + offset 3px
ARIA Labels sémantiques sur tous les formulaires et boutons icône aria-label, aria-describedby, role="alert" sur erreurs
Cible touch Zone de clic minimale 44×44px sur mobile min-height: 44px sur tous les éléments interactifs
Motion Respecter prefers-reduced-motion @media (prefers-reduced-motion: reduce) { animation: none }
HTML Structure sémantique stricte (main, header, nav, section, article) Un seul <h1> par page, hiérarchie H1→H6 respectée
Images Alt text descriptif sur toutes les images, alt="" si décoratif NuxtImg avec alt obligatoire, SVG avec aria-hidden si déco
Erreurs Messages d'erreur précis et exploitables, jamais "Erreur inconnue" role="alert" ou aria-live="polite" sur les zones d'erreur
16 — Principes d'Animation

Motion Design

--t-fast
Hover buttons, badges, micro-interactions
120ms · ease
--t-base
Focus rings, input states, card hover, nav links
200ms · ease
--t-slow
Modals, dropdowns, page transitions, overlays
300ms · ease
Page Transition
Nuxt transitions entre pages — fade + léger translateY
250ms · ease-out · translateY(6px)→(0)
Skeleton shimmer
Loading states — passage de lumière gauche→droite
1.4s · ease-in-out · infinite
Spin (loader)
Boutons en état loading, spinners globaux
0.7s · linear · infinite

Règle absolue : Toujours implémenter @media (prefers-reduced-motion: reduce) pour désactiver les animations non essentielles. Les spinners de chargement restent actifs car ils transmettent une information fonctionnelle.
